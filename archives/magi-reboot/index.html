旧终端在本日 06:21 正式停机，数据库与全部档案按命令彻底销毁，未做迁移。本报告记录新终端的构成。

一、决议

MAGI 三台对「重建」议案的表决结果全部为可決：

议题决议
内容系统Halo → Astro 静态站，文章即 Markdown / MDX
部署GitHub Actions 构建 → GitHub Pages（源站不暴露）
评论自建 Waline
统计自建 Umami，经 hud-api 汇入状态栏
INFO设计原则

界面是 NERV 本部的终端；正文是一份干净的机密档案。特效只负责氛围，不能挡住阅读。右上角的 FX 可以随时把特效降到 LOW 或 OFF。

二、部署链路

flowchart LR
  A[git push main] --> B[GitHub Actions]
  B -->|bun run build| C[dist/ + pagefind]
  C -->|git push -f| D[(nerv-base.github.io)]
  D --> E[GitHub Pages]
  E --> F((nerv-base.com))

构建脚本在最前面执行字体子集化：标题字体只保留站内真正用到的字形。

CAUTION注意

产物里必须带 .nojekyll，否则 GitHub Pages 会把 _astro/ 这类下划线目录当成 Jekyll 私有目录吞掉，全站样式丢失。

三、同步率估算

S(t)=S0​+∫0t​∂τ∂Φ​dτ,S0​≈41.3%

行内公式也可以用，例如 eiπ+1=0。

  • 右上角的三个六边形用来切换配色：MAGI / 初号机 / 二号机。
